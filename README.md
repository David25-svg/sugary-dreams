# Sugary Dreams Website

Brooklyn, New York custom sweets website for Sugary Dreams.

## What this version is
This build keeps the V2 design and layout, including the three-photo hero, real portfolio gallery, and the **Email Your Inquiry / Message on Instagram** order section.

### Updates in this version
- Broader messaging for cakes, cupcakes, cookies, cake pops, and custom sweets
- Terms of Service page
- Refund & Cancellation Policy page
- Privacy Policy page
- Strict non-refundable deposit language
- Policy links in the footer
- Existing V2 styling and portfolio photography preserved

## GitHub Pages upload
Upload the contents of this folder directly to the repository root. `index.html`, `styles.css`, and `script.js` must sit at the root beside the `images` folder.

Repository structure:

```
index.html
styles.css
script.js
terms.html
refund-policy.html
privacy.html
Sugary Dreams.jpg
images/
```

Then use GitHub **Settings → Pages → Deploy from a branch → main → / (root)**.
